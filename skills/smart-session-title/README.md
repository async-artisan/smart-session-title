# smart-session-title 管理技能

本技能随完整插件安装，用于预览和管理话题标题、查看用量以及配置可选的闲置归档。自动命名由插件的后台 Hook 执行。

## 使用

安装后可以说“预览这个话题的新标题”“暂停自动命名”或“查看命名用量”。安装入口和功能说明见[插件 README](../../README.md)，操作流程见 [SKILL.md](SKILL.md)。请安装完整插件，单独复制此技能目录不会包含后台程序。

## 兼容性与依赖

需要 Python 3.10+、已登录的本地 AI助手 CLI 和宿主工具。macOS 已实测；Windows 与 Linux 已通过自动化测试，桌面完整流程仍待实测。云端不支持后台入口。

## 数据与权限边界

命名读取近期对话并使用账号模型额度，只改标题元数据，不往原话题添加消息。归档默认关闭，需用户认可后启用；已归档话题不重新评估。用量账本不保存对话原文。
